# API-тесты для Stellar Burgers

Проект с автоматизированными тестами для проверки API [Stellar Burgers](https://stellarburgers.education-services.ru/).  
Тесты покрывают основные сценарии работы с пользователями и заказами.

---

## Что тестируется

### Пользователи
- **Создание пользователя**:
  - Успешная регистрация уникального пользователя.
  - Попытка регистрации уже существующего пользователя (ошибка 403).
  - Попытка регистрации без одного из обязательных полей (`email`, `password`, `name`) – ошибка 403.

- **Логин пользователя**:
  - Успешный вход существующего пользователя.
  - Вход с неверным логином и/или паролем – ошибка 401.

### Заказы
- **Создание заказа**:
  - С авторизацией (валидный токен).
  - Без авторизации (заказ создаётся, но пользователь не привязан).
  - С валидными ингредиентами.
  - Без ингредиентов – ошибка 400.
  - С неверным хешем ингредиента – ошибка 500.

---

## Технологии

- **Python 3.14** 
- **pytest** – фреймворк для тестирования
- **requests** – для HTTP-запросов
- **allure-pytest** – для генерации отчётов
- **random / string** – для генерации уникальных тестовых данных

## Создание и активация виртуального окружения
- python -m venv .venv
- source .venv/Scripts/activate   # для Windows Git Bash

## Запуск тестов
- pytest tests/ -v --alluredir=allure_results

##  Генерация Allure-отчёта
- allure serve allure_results

## Результаты тестов
- На момент сдачи проекта все 14 тестов проходят успешно

## Особенности реализации
- Автоматическая очистка – каждый созданный пользователь удаляется после завершения теста (вызов DELETE /api/auth/user).

- Динамическое получение ингредиентов – перед выполнением тестов заказов отправляется GET-запрос к /api/ingredients, чтобы получить актуальные ID ингредиентов (с fallback на запасные ID из документации).

- Генерация уникальных данных – для каждого теста создаются случайные email, пароль и имя, чтобы избежать конфликтов.
